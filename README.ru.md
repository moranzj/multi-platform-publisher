## Что он делает

Заполняете форму **один раз** — инструмент открывает страницы загрузки трёх платформ в вашем Chrome/Edge и вносит всё: загрузку видео, заголовок, описание, хэштеги, обложку и отложенную публикацию. По завершении страницы остаются открытыми — вы их проверяете и сами нажимаете «Опубликовать». Инструмент никогда не отправляет без вашего ведома.

- **Bilibili / Kuaishou / Douyin** — одно видео, пакетная публикация
- Заголовки и описания для каждой платформы, хэштеги, обложка (загрузить картинку или автоматически взять первый кадр видео)
- **Немедленная или отложенная публикация** (окна проверяются по платформам: Bilibili +5 мин–15 дней, Kuaishou +1 ч–14 дней, Douyin +2 ч–14 дней)
- Тег «игровой подвес» для Douyin (у веб-версии Kuaishou такого пункта нет)
- Предпросмотр и проверки до открытия чего-либо: длина заголовка/описания, число тегов, пропорции обложки, размер файла
- Живой журнал, скриншоты каждого шага, шаблоны истории (до 50)
- Без браузерных расширений — достаточно один раз войти по QR-коду на каждую платформу

> Интерфейс на китайском; [руководство](docs/tutorial-en.md) объясняет каждое поле со скриншотами.

## Скачивание и запуск (Windows 10/11)

1. Скачайте `multi-platform-publisher-<version>-exe.zip` со страницы [Releases](https://github.com/moranzj/multi-platform-publisher/releases/latest).
2. Распакуйте в любую папку **с правом записи** (не в Program Files).
3. Дважды щёлкните **`多平台发布器.exe`** — нужны только Chrome или Edge. Первый запуск: нажмите «重新登录» (повторный вход) и отсканируйте QR-код один раз для каждой платформы.

> Exe не подписан, поэтому некоторые антивирусы могут его помечать — типичное ложное срабатывание PyInstaller; добавьте в белый список. Нужен вариант из исходников? `git clone` + `setup.bat` (Python 3.9+).

```powershell
python cli.py doctor    # самопроверка окружения
python cli.py login     # вход по QR, три вкладки
python cli.py publish --video "D:\v\clip.mp4" --title "Заголовок" --ks-topics "#тег1 #тег2" --date 2026-11-20 --time 06:00
```

Поведение по умолчанию: заполнить всё и **остановиться** — вы проверяете страницы и сами нажимаете «Опубликовать» (`--auto` включает автосообщение; `--now` публикует немедленно).

## Частые вопросы

| Симптом | Решение |
|---|---|
| Зависает на странице входа | Сессия истекла — «重新登录» и отсканировать снова |
| «profile is busy» | Закройте окно браузера от прошлого запуска |
| Антивирус помечает exe | Ложное срабатывание PyInstaller — белый список |
| Хэштег не превратился в «пилюлю» | Темы нет на платформе — переформулируйте |
| CAPTCHA | Пройдите один раз вручную; очень частая публикация может вызвать проверки |

## Примечания и ограничения

- Платформы обрабатываются по очереди; ~3–8 мин на видео (зависит от размера файла)
- Сессия хранится в `profile/` — **никогда никому её не передавайте** (это и есть ваши аккаунты)
- Редизайн платформы может сломать селекторы; правки вносятся в `platforms/<платформа>.py`
- Это не официальный API, проект не связан с Bilibili, Kuaishou или Douyin. Автоматизация браузера может нарушать правила платформ — тестируйте на запасном аккаунте и публикуйте ответственно, на свой риск.
