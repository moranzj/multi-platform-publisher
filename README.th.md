## ทำอะไรได้บ้าง

กรอกฟอร์ม **ครั้งเดียว** — โปรแกรมจะเปิดหน้าอัปโหลดของทั้งสามแพลตฟอร์มใน Chrome/Edge ของคุณ แล้วกรอกทุกอย่างให้: อัปโหลดวิดีโอ ชื่อเรื่อง คำอธิบาย แฮชแท็ก ภาพหน้าปก และการตั้งเวลาโพสต์ เสร็จแล้วหน้าเว็บจะค้างไว้ให้ — คุณตรวจสอบเองและกด “เผยแพร่” เอง โปรแกรมจะไม่ส่งเองโดยที่คุณไม่รู้

- **Bilibili / Kuaishou / Douyin** — วิดีโอเดียว โพสต์หลายแพลตฟอร์ม
- ชื่อเรื่อง & คำอธิบายแยกตามแพลตฟอร์ม แฮชแท็ก ภาพหน้าปก (อัปโหลดรูป หรือใช้เฟรมแรกของวิดีโออัตโนมัติ)
- **โพสต์ทันที หรือตั้งเวลา** (ตรวจสอบช่วงเวลาตามแพลตฟอร์ม: Bilibili +5 นาที–15 วัน, Kuaishou +1 ชม.–14 วัน, Douyin +2 ชม.–14 วัน)
- แท็ก “จับจอยเกม” สำหรับ Douyin (หน้าเว็บของ Kuaishou ไม่มีช่องนี้)
- พรีวิว & ตรวจสอบก่อนเปิดอะไร: ความยาวชื่อ/คำอธิบาย จำนวนแท็ก สัดส่วนภาพปก ขนาดไฟล์
- บันทึกการทำงานสด ภาพหน้าจอรายขั้นตอน เทมเพลตประวัติ (สูงสุด 50 รายการ)
- ไม่ต้องใช้ส่วนเสริมเบราว์เซอร์ — ล็อกอินด้วย QR ครั้งเดียวต่อแพลตฟอร์ม แล้วใช้ซ้ำได้เรื่อย ๆ

> หน้าต่างโปรแกรมเป็นภาษาจีน; [คู่มือ](docs/tutorial-en.md) อธิบายทุกช่องพร้อมภาพหน้าจอ

## ดาวน์โหลด & เริ่มใช้ (Windows 10/11)

1. ดาวน์โหลด `multi-platform-publisher-<version>-exe.zip` จาก [Releases](https://github.com/moranzj/multi-platform-publisher/releases/latest)
2. แตกไฟล์ลงโฟลเดอร์ที่ **เขียนได้** (อย่าวางใน Program Files)
3. ดับเบิลคลิก **`多平台发布器.exe`** — ต้องมีแค่ Chrome หรือ Edge ใช้ครั้งแรกกด “重新登录” (ล็อกอินใหม่) แล้วสแกน QR หนึ่งครั้งต่อแพลตฟอร์ม

> exe ไม่มีลายเซ็นดิจิทัล บางโปรแกรมป้องกันไวรัสอาจแจ้งเตือน — เป็น false positive ทั่วไปของ PyInstaller เพิ่มเข้า whitelist ได้ อยากใช้จากซอร์สโค้ด? `git clone` + `setup.bat` (Python 3.9+)

```powershell
python cli.py doctor    # ตรวจสอบสภาพแวดล้อมอัตโนมัติ
python cli.py login     # ล็อกอินด้วย QR สามแท็บ
python cli.py publish --video "D:\v\clip.mp4" --title "ชื่อเรื่อง" --ks-topics "#แท็ก1 #แท็ก2" --date 2026-11-20 --time 06:00
```

พฤติกรรมค่าเริ่มต้น: กรอกทุกอย่างแล้ว **หยุดรอ** — คุณตรวจหน้าเว็บแล้วกดเผยแพร่เอง (`--auto` เปิดส่งอัตโนมัติ; `--now` เผยแพร่ทันที)

## คำถามที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| ค้างที่หน้าล็อกอิน | เซสชันหมดอายุ — “重新登录” แล้วสแกนใหม่ |
| “profile is busy” | ปิดหน้าต่างเบราว์เซอร์จากรอบก่อน |
| โปรแกรมป้องกันไวรัสแจ้งเตือน exe | false positive ของ PyInstaller — เพิ่ม whitelist |
| แฮชแท็กไม่กลายเป็น “แคปซูล” | หัวข้อนี้ไม่มีในแพลตฟอร์ม — เปลี่ยนวิธีเขียน |
| CAPTCHA | แก้เองหนึ่งครั้ง; โพสต์ถี่มากอาจถูกแพลตฟอร์มตรวจสอบ |

## ข้อจำกัด

- สามแพลตฟอร์มทำงานทีละตัว; ~3–8 นาทีต่อวิดีโอ (ขึ้นกับขนาดไฟล์)
- เซสชันล็อกอินอยู่ใน `profile/` — **ห้ามแชร์เด็ดขาด** (นั่นคือบัญชีของคุณ)
- แพลตฟอร์มเปลี่ยนหน้าเว็บอาจทำให้ selector พัง; แก้ที่ `platforms/<platform>.py`
- ไม่ใช่ API ทางการ และไม่เกี่ยวข้องกับ Bilibili, Kuaishou หรือ Douyin การใช้ automation อาจขัดต่อข้อกำหนดของแพลตฟอร์ม — ทดสอบกับบัญชีสำรอง และโพสต์อย่างรับผิดชอบ ยอมรับความเสี่ยงเอง
