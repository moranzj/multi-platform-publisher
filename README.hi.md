## यह क्या करता है

फ़ॉर्म **एक बार** भरें — टूल आपके Chrome/Edge में तीनों प्लेटफ़ॉर्म के अपलोड पेज खोलकर सब कुछ भर देता है: वीडियो अपलोड, शीर्षक, विवरण, हैशटैग, कवर और शेड्यूल। पूरा होने पर पेज वैसे ही खुले रहते हैं — आप उन्हें देखकर स्वयं “Publish” दबाते हैं। टूल आपकी अनुमति के बिना कभी सबमिट नहीं करता।

- **बिलीबिली / कुआइशोउ / दौइन** — एक वीडियो, बैच प्रकाशन
- प्रति-प्लेटफ़ॉर्म शीर्षक और विवरण, हैशटैग, कवर (छवि अपलोड करें या वीडियो का पहला फ़्रेम अपने-आप उपयोग हो)
- **तुरंत या निर्धारित समय पर प्रकाशन** (प्रत्येक प्लेटफ़ॉर्म की समय-सीमा जाँची जाती है: बिलीबिली +5 मिनट–15 दिन, कुआइशोउ +1 घंटा–14 दिन, दौइन +2 घंटे–14 दिन)
- दौइन के लिए “गेम पेंडेंट” टैग (कुआइशोउ के वेब पेज में यह विकल्प नहीं है)
- कुछ खुलने से पहले प्रीव्यू और जाँच: शीर्षक/विवरण लंबाई, टैग संख्या, कवर अनुपात, फ़ाइल आकार
- लाइव रन लॉग, हर चरण के स्क्रीनशॉट, इतिहास टेम्पलेट (50 तक)
- कोई ब्राउज़र एक्सटेंशन नहीं — हर प्लेटफ़ॉर्म पर QR कोड से एक बार लॉगिन करें, सेशन बना रहता है

> ऐप का UI चीनी भाषा में है; [ट्यूटोरियल](docs/tutorial-en.md) हर फ़ील्ड स्क्रीनशॉट सहित समझाता है।

## डाउनलोड और चलाना (Windows 10/11)

1. [Releases](https://github.com/moranzj/multi-platform-publisher/releases/latest) से `multi-platform-publisher-<version>-exe.zip` लें।
2. किसी **लिखने-योग्य** फ़ोल्डर में अनज़िप करें (Program Files में नहीं)।
3. **`多平台发布器.exe`** पर डबल-क्लिक करें — केवल Chrome या Edge चाहिए। पहली बार: “重新登录” (फिर से लॉगिन) दबाएँ और हर प्लेटफ़ॉर्म का QR कोड एक बार स्कैन करें।

> exe अहस्ताक्षरित है, इसलिए कुछ एंटीवायरस इसे फ़्लैग कर सकते हैं — PyInstaller का सामान्य फ़ॉल्स पॉज़िटिव; व्हाइटलिस्ट में डाल दें। सोर्स से चलाना चाहें? `git clone` + `setup.bat` (Python 3.9+)।

```powershell
python cli.py doctor    # पर्यावरण स्वयं-जाँच
python cli.py login     # QR लॉगिन, तीन टैब
python cli.py publish --video "D:\v\clip.mp4" --title "शीर्षक" --ks-topics "#टैग1 #टैग2" --date 2026-11-20 --time 06:00
```

डिफ़ॉल्ट व्यवहार: सब भरकर **रुक जाना** — आप पेज जाँचकर स्वयं Publish दबाते हैं (`--auto` ऑटो-सबमिट चालू करता है; `--now` तुरंत प्रकाशित करता है)।

## अक्सर पूछे जाने वाले प्रश्न

| लक्षण | समाधान |
|---|---|
| लॉगिन पेज पर अटक जाता है | सेशन समाप्त — “重新登录” दबाकर दोबारा स्कैन करें |
| “profile is busy” | पिछली रन का ब्राउज़र विंडो बंद करें |
| एंटीवायरस exe को फ़्लैग करे | PyInstaller फ़ॉल्स पॉज़िटिव — व्हाइटलिस्ट करें |
| हैशटैग “पिल” नहीं बना | वह टॉपिक प्लेटफ़ॉर्म पर मौजूद नहीं — शब्द बदलें |
| CAPTCHA | एक बार हाथ से हल करें; बहुत बार प्रकाशन प्लेटफ़ॉर्म जाँच ट्रिगर कर सकता है |

## टिप्पणियाँ और सीमाएँ

- तीनों प्लेटफ़ॉर्म क्रम में चलते हैं; प्रति वीडियो ~3–8 मिनट (फ़ाइल आकार पर निर्भर)
- लॉगिन सेशन `profile/` में रहता है — **कभी साझा न करें** (यही आपके अकाउंट हैं)
- प्लेटफ़ॉर्म के रीडिज़ाइन से सेलेक्टर टूट सकते हैं; सुधार `platforms/<platform>.py` में होते हैं
- यह कोई आधिकारिक API नहीं है और बिलीबिली, कुआइशोउ या दौइन से संबद्ध नहीं है। ब्राउज़र ऑटोमेशन प्लेटफ़ॉर्म की शर्तों का उल्लंघन कर सकता है — किसी अतिरिक्त अकाउंट से जाँचें और ज़िम्मेदारी से, अपने जोखिम पर प्रकाशित करें।
