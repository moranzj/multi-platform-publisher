# 多平台视频发布器 · 图文教程

> 从零开始：下载 → 登录 → 填一次表 → 自己点发布。全程 10 分钟左右。
>
> 其他语言：[English](tutorial-en.md)

---

## 这个工具是干什么的？

一条视频要发 B站、快手、抖音三个平台？每个平台都要：打开网页 → 登录 → 上传视频 → 填标题 → 填文案 → 填话题 → 设封面 → （可能还要设定时）。**同样的信息填三遍，点几十下。**

这个工具把这些全部自动化：**你填一次表，它替你把三个平台的发布页都填好**——视频上传、标题、文案、话题、封面、定时，全部到位。最后一步「发布」按钮留给你自己点，账号更安全。

## 第 1 步：下载

**方式 A：exe 免安装版（推荐，不用装 Python）**

1. 打开 [Releases 页面](https://github.com/moranzj/multi-platform-publisher/releases/latest)，下载 `multi-platform-publisher-<版本>-exe.zip`。
2. 解压到任意**可写**目录（比如 `D:\多平台发布器`）。不要放 Program Files（程序要在自己目录里写配置和日志）。
3. 双击 **`多平台发布器.exe`**。前提：电脑上要有 Chrome 或 Edge（Win10/11 一般自带 Edge）。

> exe 没有数字签名，个别杀毒软件可能误报，加白名单即可。这是 PyInstaller 打包的常见现象。

**方式 B：源码版（要装 Python 3.9+）**

```powershell
git clone https://github.com/moranzj/multi-platform-publisher.git
cd multi-platform-publisher
setup.bat          # 一键安装：建虚拟环境、装依赖、建桌面快捷方式
```

装好后双击桌面上的「多平台视频发布器」或项目里的 `启动.bat`。

---

## 第 2 步：首次登录（三个平台各扫码一次）

点界面右下角的 **「重新登录」**（源码版也可以双击 `登录.bat`）：

1. 会弹出一个浏览器窗口，里面有 **B站 / 快手 / 抖音** 三个标签页。
2. 用手机 App 分别扫码登录三个平台。
3. 三个都登好后窗口自动关闭，**不用按回车**。

登录态保存在程序目录的 `profile\` 文件夹里，之后每次运行都免登录。

> ⚠️ `profile\` 里是你的登录 Cookie，**不要发给任何人**——等于把账号交出去。
>
> ⚠️ 如果上次开的浏览器窗口还没关，新任务会提示「profile 被占用」——把旧窗口关掉再跑。

## 第 3 步：填一次表

对照上面的界面图，从上往下：

| 字段 | 填什么 | 说明 |
|---|---|---|
| **视频文件** | 点「浏览…」选 mp4 | 选完会自动用文件名填标题，并在同目录找同名封面（`视频-封面.jpg` 等） |
| **封面图片** | 可留空 | 留空 = 三个平台统一用**视频第一帧**当封面；指定了就都传这张图 |
| **标题** | 视频标题 | 一般自动填好，可改 |
| **文案** | 简介/描述 | 三个平台通用；要差异化就点「分平台文案…」 |
| **B站标签 / 话题** | 逗号分隔 | 如 `三国杀,桌游棋牌` |
| **快手话题 / 抖音话题** | `#` 开头空格分隔 | `#` 不写也行，程序自动补；逗号/顿号也能当分隔符 |
| **抖音游戏** | 游戏名，可留空 | 填了就给抖音作品挂「游戏手柄」挂件（快手网页端没这个入口） |
| **历史** | 下拉框 | 每次开跑自动存成模板（最多 50 条），下次直接选一条回填 |

**话题写法示例**——下面两种写法等价，都会拆成 4 个话题：

```
三国杀 三国杀锦囊妙会 随时随地杀一下 三国杀将星筑梦
#三国杀 #三国杀锦囊妙会 #随时随地杀一下 #三国杀将星筑梦
```

> B站话题会走「搜索更多话题」自动匹配：先找名字完全一样的，找不到就选播放量最高的（日志里写清楚选了哪个）。抖音/快手会校验话题是否真的变成了胶囊，没变成的会在日志里点名。

## 第 4 步：预览与检查

点 **「预览 / 检查…」**（不打开浏览器），会列出：

- 每个平台**最终**的标题、简介/作品描述、标签和话题
- 标题/描述长度、标签数量有没有超（B站标题 80 字、抖音标题 30 字等）
- 视频文件是否存在、是否超 4GB；封面尺寸比例是否常见

有问题就回去改，检查只是提醒，不会替你截断文案。

---

## 第 5 步：选发布方式

| 选项 | 行为 |
|---|---|
| **立即发布** | 不设日期，网页上点发布就当场发出 |
| **定时发布** | 选日期时间（默认明天 06:00，可手输任意时分，有「今天/明天」「06:00/18:00」快捷键），三平台定时排队 |

各平台定时窗口不同，超出会提醒：**B站 5 分钟 ~ 15 天，快手 1 小时 ~ 14 天，抖音 2 小时 ~ 14 天**（三个都勾时按最严的算）。

---

## 第 6 步：开始填表 → 核对 → 自己点发布

1. 勾选要发的平台（默认三个全勾）。
2. 「跑完之后」保持默认第一项：**填好就停，页面保持打开**。
3. 点 **「开始填表」**，右侧日志一条条滚动，能看到每一步在干什么：

![运行日志](images/app-run.png)

4. 跑完后切到浏览器，**逐个标签页肉眼核对**——标题、话题、封面、定时。
5. 没问题就**自己点「发布 / 立即投稿」**。

> 为什么不自动提交？工具只负责填表，发布按钮永远在你手里：
> 万一识别错了，你看到的是填好的页面而不是已经发出去的视频。想全自动也有
> 「填好并自动提交」选项（会再弹一次确认），建议验证稳定后再用。

---

## 第 7 步：看结果

跑完界面右侧显示「已结束」，耗时一目了然：

![填写完成](images/app-done.png)

- 提交成功的判定：页面跳到「作品管理 / 内容管理」，或出现「发布成功」横幅（日志里写「已跳转到管理页」）。
- 每次运行的完整日志和各阶段截图都在 `logs\<时间戳>-任务\` 下，出问题把 `run.log` 最后几行和最后一张截图发出来就能定位。

## 常见问题

| 现象 | 处理 |
|---|---|
| 卡在登录页 | 登录态过期，点「重新登录」再扫一次 |
| 「profile 被占用」 | 关掉上次没关的浏览器窗口再跑 |
| 杀毒软件报 exe | PyInstaller 常见误报，加白名单 |
| 话题没变成胶囊 | 平台里没这个话题，换个写法或先去平台建话题 |
| 定时没设上 | 程序会自动停下并报出来，不会带着「立即发布」误提交 |
| 上传很慢 | 三平台串行跑，一条视频约 3–8 分钟（取决于体积），正常 |
| 遇到验证码 | 手动过一次；高频发布可能触发平台风控 |
| 想改自动填的细节 | 改 `platforms/<平台>.py` 顶部的选择器常量 |

## 一句话总结

**你填一次表 → 工具替你把三个平台填好 → 你亲眼核对 → 你亲手点发布。**

本工具通过浏览器自动化操作平台页面，不是官方 API；与 B站 / 快手 / 抖音 无隶属关系。请遵守各平台社区规范，理性发布，风险自负。详见 [MIT License](../LICENSE)。
